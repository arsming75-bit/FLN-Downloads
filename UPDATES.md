# Updating FLN and artwork

Application updates and artwork downloads are separate. A new application version does not normally require downloading the artwork again. Each release will identify the compatible asset pack and any special upgrade instructions.

## Application update

1. Read the new release notes on the [official Releases page](https://github.com/arsming75-bit/FLN-Downloads/releases).
2. Finish any work and save articles you want to keep. Back up your FLN library and settings before upgrading. The launcher's **Open Data** button opens the default data location; also back up a separately selected library if you use one.
3. Select **Exit FLN** in the launcher before installing the update.
4. Download the new installer and verify it using the [installation guide](INSTALL.md#windows-warnings-and-verification).
5. Run the installer against the existing FLN installation folder. A routine update does not require uninstalling first.
6. Reopen FLN and confirm the version, artwork selection, saved stories, and dynasty history.

The upgrade process is designed to preserve your library and settings. Keep your backup until you have checked the update. Do not install an older version over a newer one unless that release explicitly documents a supported rollback.

Use **Check for Updates** in the launcher for update guidance. This page does not promise automatic background downloads or installation. The release instructions remain the reference for each update.

## Standard artwork update

Download a new standard artwork pack only when release notes call for one. Extract it into a separate permanent folder, then use **Change Artwork** to select it. Keep the previous folder until the replacement has verified successfully.

## Portrait refresh

For updated player/recruit or coach portraits, use the appropriate **Choose Folder** control under **Change Artwork**. If files in the selected custom folder have changed, use its **Refresh** control and review the result before applying. Custom packs are optional and must use compatible portrait mapping.
