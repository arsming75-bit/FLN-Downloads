## Before you install

- FLN is currently **unsigned**. Windows may show an unknown-publisher or SmartScreen warning. Read [Windows warnings and verification](INSTALL.md#windows-warnings-and-verification) before running an installer.
- The target platform is Windows 10/11, 64-bit. Release notes will identify what has actually been tested; this is not a claim that every Windows configuration is validated.
- Save import currently needs at least **5 GiB of available memory**. Close other large applications if FLN reports insufficient memory.
- Keep the extracted artwork folder somewhere permanent, outside FLN's installation folder.
- AI writing is optional. Provider requests may incur charges on your own account.
